# Fixed slot contract for template 3

SOURCE: map, original Spot names/categories, managed photos, category icons, logo, decoration geometry. PAPER_OVERRIDE: per-Spot summary. Photo choice is a Paper-only selection of SOURCE media and must belong to that same Spot. PAPER_ORIGINAL: title, subtitle, intro, sectionHeading, notice, QR label, footer. Derived numbers identify selected Spots, never a route.

header/title and subtitle have bounded typography. intro/notice/footer/QR can be edited, hidden and reset. categoryLegend and guide can be hidden, with no leaked continuation content. photoFeature controls card/strip source photos. A Spot image selection can reset to its first existing photo. No URLs pasted into free image controls, no free positioning, resizing or generic blocks.

The inspector exposes named controls and the text document outside the page image. Preview regions can select an editor, but keyboard operation does not require pixel clicking. Selection and order are explicit, with up/down controls. Viewport is adjusted by a visual frame and named buttons/arrow keys. Paper edits never write Source.
