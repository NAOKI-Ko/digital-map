# 公開マップ探索状態の契約（実装前、2026-09-23）

状態は `floorId`、カテゴリーID集合（OR）、`selectedSpotId`、MapLibreカメラ（center/zoom/bearing/pitch）、詳細パネル（閉/概要/展開）、情報・フロア選択overlayで考える。情報・フロア選択は排他的な一時UI。Spot詳細は地図と並行して表示する。

| 操作 | 保持する状態 | 変える状態 |
|---|---|---|
| カテゴリー選択/解除 | フロア、カメラ、既存OR条件 | カテゴリー集合を更新。選択Spotが対象外になった時だけ詳細を閉じる。再fitしない |
| PIN選択 | フロア、カテゴリー、zoom/bearing/pitch | 選択Spotと概要パネルを開く。PINがパネルに隠れる場合のみ最小パン。Spot座標は不変 |
| 詳細展開/縮小 | フロア、カテゴリー、Spot、カメラ | パネル高さ。展開でPINが隠れる時のみ最小パン。再fitしない |
| 詳細を閉じる/探索へ戻る | フロア、カテゴリー、**現在の**カメラ（パネル中にユーザーが動かした位置も含む） | 選択Spotとパネルを閉じる。閉じたSpotのPINへfocusを戻す。カメラを巻き戻さない |
| パン/ズーム/回転/傾き | フロア、カテゴリー、Spot、パネル | カメラのみ。詳細表示中も操作可能。位置に応じて角度復帰を表示 |
| 向きを戻す | フロア、カテゴリー、Spot、パネル、center/zoom | bearing 0°、pitchを採用した初期角度へ。fitしない |
| 全体を表示 | フロア、カテゴリー、Spot、パネル | 画像全体が見えるcenter/zoomと、全景用の角度へfit。利用者が明示した時だけ |
| フロア切替 | 新フロアの公開情報、言語 | selectedSpot・カテゴリー解除、新フロアをfit。管理エディターのカメラには影響しない |
| 言語切替 | フロア/カテゴリー/Spot/カメラを可能な限り保持 | 公開文字列のみ切替。ルート再取得で消える状態は回帰事項として確認 |

開発用pitch比較は公開機能ではない。同一center/zoom比較ではangle以外を固定し、角度別fit比較は各pitchで初期center/zoomを計算する。
