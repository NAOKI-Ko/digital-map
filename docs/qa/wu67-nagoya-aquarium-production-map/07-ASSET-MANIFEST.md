# Asset provenance

Machine-readable manifest: assets/visitor-maps/nagoya-aquarium/asset-manifest.json. All new map and pictogram SVG/PNG assets are **GENERATED**, specifically structured original vector authored by Codex for this task. No map was delegated to bitmap image generation; no official illustration, icon, photograph or outline was copied or directly traced.

Five editable floor SVGs and eighteen editable pictogram SVGs are retained. PNG map exports are 2400×3660; native-PIN pictograms are 128×128. Render source is versioned, with Japanese font resolution verified on the authoring host. Windows consumes the rendered assets; it does not substitute fonts.

Official leaflet, website and live digital map are references only, stored outside the application asset tree. Existing three animal photographs remain unchanged, including the description that they are general animal images rather than photos of this aquarium. Original author/license/attribution strings remain in the existing Spot descriptions; compare WU-66 spot-detail audit and the before/after preservation check.

QA installation plan identifies exact asset digests, Floor IDs, Spot IDs, category associations and normalized coordinates. No source reference image is present in that plan. The installer rejects file digest drift and refuses Production.
