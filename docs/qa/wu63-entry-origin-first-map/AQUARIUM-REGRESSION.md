# Aquarium regression

After Windows deployment, the existing Aquarium UAT account's authenticated Map Home showed the original `【非公式UAT】名古屋港水族館 館内マップ` and 37 registered Spots. The Publish page remained **公開中**, showed its existing release history, and displayed `https://eyes-retention-judgment-neural.trycloudflare.com/nagoya-aquarium-uat-20260928` in the share field with a generated QR PNG. Its Map Home public link used the same current host. The public visitor page opened over HTTPS and rendered the Aquarium map with its placed Spots. The account was logged out before fresh-account acceptance; no Aquarium content was edited or republished.

A SELECT-only database check returned five Aquarium Floors and 37 Aquarium Spots after deployment. It also found three pre-existing Arimatsu Maps. The normal pre-deploy backup includes the entire database, media and public storage. No Arimatsu data was edited. The publish-page QR derives from the displayed public URL through the same `publicUrl` prop; its pixels were not independently decoded. Existing Paper/PDF exports with QR pixels were not regenerated and may still encode an older quick-tunnel host until re-exported.
